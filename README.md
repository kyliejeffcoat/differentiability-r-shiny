# Understanding Differentiability Using R Shiny

This project is an interactive R Shiny app I created for my Mathematics in AI course at Texas A&M University–Central Texas.

I chose differentiability because it was something I struggled with when we first learned it. I wanted to create something that would let me change the numbers and actually see what was happening instead of just working through formulas.

## What the App Does

The app allows users to:
- Choose between four different functions.
- Change the point being tested.
- Adjust the value of h.
- View the graph of the function.
- Compare left-hand and right-hand slope calculations.

The goal is to show why some functions have a derivative at a certain point while others do not.

## What I Learned

One of the biggest things I learned was that getting similar slope values from both sides does not always mean a function is differentiable. I also learned how important it is to test smaller values of h and consider whether the slopes are approaching a finite number.

If I continued improving the app, I would work on making its differentiability classification more accurate.
